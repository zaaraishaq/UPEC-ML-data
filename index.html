Project Details

Web-Based UPEC Surveillance Tool

This database is designed for the genomic characterization and surveillance of multidrug-resistant uropathogenic Escherichia coli (UPEC), utilizing comparative genomics and interpretable machine learning frameworks to prioritize lineage-specific genomic features.
